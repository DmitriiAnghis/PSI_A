# Лаб 1 — консольный генератор экзаменационных билетов

Запрашивает фамилию и имя, выдаёт билет 1–20 и сразу дописывает строку в `journal.xlsx`.
ESC во время ввода — выход.
Имя и фамилия проверяются: поле должно начинаться с заглавной буквы;
допускаются буквы Unicode, пробелы, дефисы и апострофы. Цифры и прочие
символы отклоняются с повторным запросом.

Проверка имени, генератор билетов, хранилище Excel, консольный интерфейс
и сценарий приложения разделены. Зависимости сценария передаются через
небольшие интерфейсы, поэтому их реализации можно заменять независимо.

## Запуск
```bash
pip install -r requirements.txt
python ticket_generator.py
```

## Тесты
```bash
python -m pytest
```
