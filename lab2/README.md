# Лаб 2 — генератор экзаменационных билетов с GUI

Окно на Tkinter: выбор группы (листы `students.xlsx`) → выбор студента → «Сгенерировать билет».
Показывает номер и три вопроса из `tickets.docx`, сразу дописывает строку в `results.xlsx`.
Повторный выбор того же студента выдаёт номер из его первой записи и пишет «Повтор = да».
Esc закрывает окно с билетом, приложение остаётся открытым.

Кнопка «+ Добавить студента» дописывает студента в лист выбранной группы `students.xlsx`.
Фамилия и имя проверяются: не пусто, без цифр, только буквы (пробел, дефис и апостроф
между частями), первая буква заглавная, без повтора в той же группе.

Если `results.xlsx` или `students.xlsx` открыт в Excel, программа на Windows сама сохраняет
и закрывает эту книгу (через pywin32) и записывает данные. Другие книги Excel не трогаются.
Если закрыть не удалось, появляется окно «Файл занят» с кнопкой «Повторить».

## Файлы
- `data/students.xlsx` — лист = группа, A — Фамилия, B — Имя, данные со 2-й строки.
- `data/tickets.docx` — «Билет N» и под ним «1. …», «2. …», «3. …».
- `data/results.xlsx` — журнал, создаётся при первом запуске.
- `tickets.log` — лог пропущенных билетов и ошибок.

Тестовые входные файлы пересоздаются командой `python make_sample_data.py`.

## Запуск
```bash
pip install -r requirements.txt
python app.py
```
