# Лаб 2 — генератор экзаменационных билетов с GUI

Одно окно Tkinter с вкладками (без всплывающих окон):

- **Билет** — выбор группы и студента, «Сгенерировать билет». Билет (номер и три вопроса
  из `tickets.docx`) показывается на этой же странице, строка сразу дописывается в
  `results.xlsx`. Повторный выбор того же студента выдаёт номер из его первой записи и пишет
  «Повтор = да». Esc очищает карточку билета.
  Под выданным билетом: «Переназначить случайно» (другой номер) или «билет № … → Назначить»
  (конкретный номер). В журнал пишется строка «переназначен», и дальше студенту выдаётся
  уже новый номер. «Выдать всей группе» выдаёт билеты всем, у кого их ещё нет, и показывает
  список. Под кнопками видно, выдан ли выбранному студенту билет и какой.
- **Студенты** — группы (листы `students.xlsx`) и студенты, поиск, добавление,
  переименование и удаление группы, добавление и удаление студента. «Изменить» исправляет
  фамилию и имя и переводит студента в другую группу; его записи в журнале меняются вместе
  с ним. «+ Списком» добавляет сразу много студентов (строка = «Фамилия Имя»): хорошие строки
  сохраняются, строки с ошибками остаются в поле с пояснением. Фамилия и имя: не пусто, без цифр, только буквы (пробел,
  дефис и апостроф между частями), первая буква заглавная, без повтора в группе. Группа:
  с заглавной буквы, буквы, цифры и дефис, не длиннее 31 символа.
- **Журнал** — содержимое `results.xlsx`, фильтр по группе, сводка (выдано, студентов,
  повторов, переназначено, самый частый билет), экспорт в CSV (`data/journal_*.csv`),
  «Открыть в Excel», «Удалить запись» (ошибочную строку). Двойной щелчок по строке открывает
  этого студента на вкладке «Билет».
- **Билеты** — все билеты из `tickets.docx` с поиском; добавить, изменить и удалить билет.
  Три непустых вопроса без повторов; номер необязателен (берётся следующий свободный).
  Пустую группу можно удалить на вкладке «Студенты».

Если `results.xlsx`, `students.xlsx` или `tickets.docx` открыт в Excel или Word, программа
на Windows сама сохраняет и закрывает этот файл (через pywin32) и записывает данные. Другие книги Excel не трогаются.
Если закрыть не удалось, под шапкой появляется полоса «Файл занят» с кнопкой «Повторить».

## Файлы
- `data/students.xlsx` — лист = группа, A — Фамилия, B — Имя, данные со 2-й строки.
- `data/tickets.docx` — «Билет N» и под ним «1. …», «2. …», «3. …».
- `data/results.xlsx` — журнал, создаётся при первом запуске.
- `tickets.log` — лог пропущенных билетов и ошибок.

Тестовые входные файлы пересоздаются командой `python make_sample_data.py`.

## Запуск
```bash
pip install -r requirements.txt
python app.py
```
